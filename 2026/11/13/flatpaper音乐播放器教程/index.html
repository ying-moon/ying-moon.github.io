Hexo + flatpaper 主题 音乐播放器搭建

适用环境：Windows / macOS 均可，Hexo 7.x，主题 flatpaper（其他 Hexo 主题同样适用，原理一致）
最终效果：博客出现一个 /music/ 音乐页，内嵌 APlayer 播放器，可播放网易云歌单、单曲、专辑等多种来源
预计耗时：10 分钟（不含踩坑；坑都帮你踩完写在这了）

一、原理先搞懂（一分钟）

整套东西由三个部分协作，缺一个播放器都不出现：

组件 角色 由谁提供
hexo-tag-aplayer Hexo 插件，在构建时把 {% meting %} 标签翻译成播放器容器 <div> npm 安装
APlayer + MetingJS 浏览器里的播放器 UI + 数据引擎，负责请求歌单、渲染界面 插件注入或 CDN 引入
Meting API 服务端接口，把网易云/QQ音乐的歌单转成通用 JSON 数据 默认 api.i-meto.com（免费公共服务）

数据流向：{% meting %} 标签 → 生成空 <div class="aplayer"> → MetingJS 拿 div 上的 data 属性去请求 Meting API → 拿到歌曲列表 → APlayer 渲染播放器。

二、配置 _config.yml 关键一步

打开站点根目录的 _config.yml（不是 themes/flatpaper/_config.yml），在文件末尾加上：

每一项是什么意思

配置 说明
enable: true 启用插件（不写默认关）
meting: true 启用 MetingJS，支持 {% meting %} 标签（不写只支持手写 {% aplayer %}）
asset_inject: true 构建时自动把 APlayer 的 JS/CSS 注入页面 <head>
cdn / style_cdn / meting_cdn 播放器三件套的引入地址，配了 CDN 就不用本地资源

为什么强烈建议配 CDN

两个原因：

  1. Windows反斜杠bug：不配 CDN 时，插件用 path.join 拼本地资源路径，Windows 下会生成 href="\assets\js\APlayer.min.js" 这样的反斜杠路径，浏览器请求必然 404，播放器死活出不来。配了 CDN，地址是原样引用的，彻底绕开这个 bug。
  2. CDN 选择要实测：网上旧教程大多推荐 jsdelivr（cdn.jsdelivr.net），国内网络环境基本连不上（实测 HTTP 状态 000）。推荐用 npmmirror：

版本号建议和本地安装的保持一致（看 node_modules/aplayer/package.json，本次用的是 aplayer 1.10.1 + meting 1.2.0）。

注意：asset_inject: false 是官方文档里的进阶用法，意思是”插件不注入资源，由主题模板自己加 <script>/<link>“。flatpaper 主题不带任何 APlayer 资源，所以对 flatpaper 用户来说这里必须写 true。如果你在网上抄到了 false 的配置，这就是播放器消失的第一个原因。

冲突提示：不要混用两套方案

不要同时写 {% meting %} 标签 + 手写 ``，两套会重复实例播放器，出现重复播放器、播放异常。

四、构建、验证、上线

1. 本地预览（注意重启）

⚠️ hexo server 不会自动感知 _config.yml 的改动。如果你之前已经开着预览服务，必须 Ctrl+C 停掉重新启动，否则你看到的还是旧配置的效果，白白怀疑人生。

浏览器打开 http://localhost:4000/music/，应该能看到播放器。

2. 五道验证关卡（不过关别急着部署）

按顺序检查，哪一关挂了就说明哪一环有问题：

  1. 插件关：package.json 里有 hexo-tag-aplayer；
  2. 配置关：_config.yml 里 aplayer.enable 和 meting 都是 true；
  3. 产物关：打开 public/music/index.html 检查——
    • <head> 里有没有 APlayer/Meting 的 <link>/<script> 引用；
    • 路径是不是正斜杠 /（Windows 反斜杠 = 404 = 播放器出不来）；
    • 正文里有没有 class="aplayer" 的 <div>；
  4. 网络关：浏览器 F12 → Network 面板，三个资源请求应该是 200，Meting API（api.i-meto.com）请求应该返回歌曲 JSON 数据；
  5. 音源关：点播放能不能出声。

症状 原因 解决
页面只有文字，完全没有播放器 asset_inject: false 且主题没自带资源，{% meting %} 只渲染出空 div 改为 true，或 CDN 配置
仍然没有播放器 Windows 下注入的本地资源路径是 \assets\js\...，反斜杠 404 用 cdn/style_cdn/meting_cdn 指向 CDN（npmmirror）
本地改了配置没变化 hexo server 不感知 _config.yml 改动 Ctrl+C 重启 hexo server

播放器在、但某首歌点不开 该歌曲在网易云无可用音源（版权/VIP 限制，实测单曲 2692670950《出格者》就返回 404） 换歌曲 ID，不是配置问题
Meting API 返回空 api.i-meto.com 是公共服务，偶发不稳定 等一会重试；重度用户可自建 MetingAPI
歌单加载出来但封面/外链失效 平台防盗链 属 Meting API 侧问题，与本地配置无关
