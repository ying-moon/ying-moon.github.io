二、基本概念（简单了解）

概念 说明
用户（User） 系统中登录和使用资源的身份
组（Group） 多个用户的集合，方便统一管理权限
UID 用户的数字编号（普通用户一般从 1000 开始）
GID 组的数字编号
家目录 用户登录后默认进入的目录，通常是 /home/用户名
Shell 用户登录后使用的命令解释器，常用 /bin/bash

参数 含义 示例
-M 密码最长有效天数 chage -M 90 zhangsan（90天后过期）
-m 密码最短使用天数（防止频繁改密） chage -m 7 zhangsan

十、常用命令速查（扩展）

类别 命令 作用
用户 useradd -m -s /bin/bash 用户名 创建用户
用户 passwd 用户名 设置密码
用户 usermod -aG 组名 用户名 追加组
用户 usermod -L / -U 用户名 锁定/解锁
用户 userdel -r 用户名 删除用户及家目录
组 groupadd 组名 创建组
组 gpasswd -a 用户 组名 添加用户到组
策略 chage -l 用户名 查看密码策略
策略 chage -M 90 用户名 设置最长有效期
权限 chown 用户:组 文件/目录 修改所有者
权限 chmod 2770 目录 设置权限+setgid
批量 for i in $(seq 1 5); do ...; done 批量操作

十一、注意事项（重要补充）

  1. CentOS 最小化安装创建用户**必须加 -m**。
  2. 使用 usermod -G 时一定要加 -a，否则会覆盖原有组。
  3. 设置共享目录时，推荐使用 2770 权限（带 setgid）。
  4. 实验结束后及时清理临时用户和组，保持系统干净。
